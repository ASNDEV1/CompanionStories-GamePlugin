# Companion Stories — game assets

Companion-focused derivative of Galanx's IntelEngine, independent of the upstream developer. The native source and migration notes are in [CompanionStories-NativePlugin](https://github.com/ASNDEV1/CompanionStories-NativePlugin).

The original `IntelEngine.esp`, quest fragment and script identities remain for save compatibility. Updated scripts retire autonomous wars, ambushes, stalking, generic quest generation, gossip and biography rewriting. Legacy duplicate actions, political dashboard and installer options are omitted. The MCM displays the new scope.

Personal story definitions are campaign-specific configuration. The generic engine does not bundle private actors or biographies. Compile the native fork and all scripts before installation. Use one complete owned package, including the unchanged ESP, rebuilt DLL, rebuilt PEX, appropriate companion configuration/prompt and retained LICENSE/NOTICE. Ordinary follower and travel actions remain with existing external mods.

No save cleaning or runtime filename renaming is part of installation. Existing unknown legacy state cannot be reconstructed and remains inert when ownership is unproven. In-game verification is still required.
